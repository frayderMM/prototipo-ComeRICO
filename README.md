# ComeRICO

Prototipo móvil desarrollado con React, Vite y Tailwind CSS para explorar packs de comida, simular pedidos y suscribirse a locales. Incluye planes semanales y mensuales con descuento, puntos, reseñas y un panel para negocios.

## Desarrollo

```sh
pnpm install
pnpm dev
```

## Compilación

```sh
pnpm build
pnpm preview
```

La aplicación es una demo: los pedidos y pagos son simulados y los datos se guardan localmente en el navegador. El plan mensual equivale a 4 semanas y aplica un 10 % de descuento en packs, sin descontar el envío.
